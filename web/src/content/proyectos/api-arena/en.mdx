API Arena is in production. The public site marks it as early access.

# A real API, tested over HTTP

You pick a challenge, build it, and send a ZIP. A sandbox builds it and hits it with real requests. It is not a paper exam.

<Figura src="./img/portada.webp" alt="API Arena homepage showing an API submission and the HTTP test results" pie="The public homepage, with the sandbox running." />

## Nine services, one pipeline

Accounts, challenges, submissions, sandbox, tests, ranking, review, metrics and notifications. PostgreSQL and Redis hold the state. Kafka moves the pipeline. The front end is React. It all closes in Docker.

Each submission leaves a replay: what was built, what failed, and where it sits on the board.
