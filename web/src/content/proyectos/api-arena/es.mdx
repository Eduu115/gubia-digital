# Una API de verdad, probada por HTTP

Eliges un reto, la implementas y la envías en un ZIP. Un sandbox la construye y la golpea con peticiones reales. No es un examen de papel.

<Figura src="./img/portada.webp" alt="Portada de API Arena con el envío de una API y el resultado de las pruebas HTTP" pie="La portada pública, con el sandbox en marcha." />

## Nueve servicios, un solo pipeline

Cuentas, retos, envíos, sandbox, pruebas, ranking, revisión, métricas y avisos. PostgreSQL y Redis guardan el estado. Kafka mueve el pipeline. El frontal es React. Todo cierra en Docker.

Cada envío deja un replay: qué se construyó, qué falló y dónde queda en el ranking.
