# Todavía en el taller

serdrive es un servidor de archivos montado en un ordenador que ya no se usaba. Los archivos se quedan en casa, fuera de un disco de terceros. La landing ya cuenta eso. El sitio público, no.

<Nota>
El dominio previsto es serdrive.com. Hoy el HTTPS no responde y el HTTP enseña el proxy por defecto, así que desde aquí no se enlaza.
</Nota>
